## Setup (5 min)

```bash
# Clone repo
git clone https://github.com/Joker5514/daw-ai-orchestration.git
cd daw-ai-orchestration

# Set API keys (choose option A or B)
# Option A: Export to shell
export ANTHROPIC_API_KEY="sk-ant-..."
export GOOGLE_API_KEY="AIza..."
export DEEPSEEK_API_KEY="sk-..."
export OPENAI_API_KEY="sk-..."

# Option B: Create .env file
echo 'ANTHROPIC_API_KEY=sk-ant-...' > .env
echo 'GOOGLE_API_KEY=AIza...' >> .env
echo 'DEEPSEEK_API_KEY=sk-...' >> .env
echo 'OPENAI_API_KEY=sk-...' >> .env

# Install dependencies
pip install -r requirements.txt 2>/dev/null || echo "Creating requirements.txt..."
```
